启动命令（input.csv 共 2147 条任务，分 3 段、3 个端口并行）

命令1 - 端口5268，索引 1~716（716条）
python main.py --port 5268 --start 1 --end 716

命令2 - 端口5269，索引 717~1431（715条）
python main.py --port 5269 --start 717 --end 1431

命令3 - 端口5270，索引 1432~2147（716条）
python main.py --port 5270 --start 1432 --end 2147

使用前注意：
- 提前用对应端口（5268/5269/5270）分别打开 3 个 Chrome 调试实例，脚本连接已有浏览器
- --end 为包含边界
- 输出：帖子 -> postData/{帖子id}.json，图片 -> imgData/{帖子id}_{图片索引}.json
